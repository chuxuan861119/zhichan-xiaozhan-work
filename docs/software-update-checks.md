# 软件更新检测：设计与验收

2026-10-05。范围为自动检测、可关闭通知、更新说明、稍后／跳过、手动检查和浏览器官方下载入口。此次不在软件内下载、执行安装包或重启，不更改文档或数据库。

## 使用与状态

- 设置 → 软件更新：默认开启自动检查新版本，不提供检查频率设置。关闭处始终显示“建议保持开启。软件更新可修复已知问题、改善使用体验，并提供分类号数据库更新。”这不保证每次发行都更新数据库。
- 正式安装版在界面就绪后延迟约 10 秒后台检查；最近成功检查不足 24 小时则跳过。之后固定每日检查一次。失败不阻塞启动或编辑；重新打开软件或手动检查可重试。
- 自动检查发现当前系统／架构的更高稳定版才显示轻量提醒，不抢焦点、不自动弹出详情。每个版本在一次运行中最多通知一次。关闭或“稍后提醒”保存 24 小时暂停；“跳过此版本”只抑制该版本的自动通知。较新版本仍会提醒。手动检查始终可看见被跳过的新版。
- 自动检测开关保存成功后立即停止计时并取消在途请求，旧响应不能重新通知。手动检查仍可使用。网络超时、格式错误、无对应平台、尚未配置渠道分别显示状态，不能误报“已是最新”。
- 帮助 → 检查更新、关于 → 检查更新打开同一详情窗口。设置中检查时保持当前页面，可主动查看详情。
- 关闭提醒即时隐藏；提醒偏好若保存失败则状态明确提示，不能让磁盘故障变成无法关闭的通知。
- 新版详情显示发布日期、纯文本变更、可选分类号数据库版本和系统要求。前往官方下载只打开已校验地址，安装由用户操作；安装前应保存文档并退出软件。
- 开发实例不访问正式渠道；需要隔离验证时使用本机测试源。隔离测试只允许本机 TLS 源；正式安装版忽略测试源环境覆盖。减少动态效果设置适用于提醒、开关和加载动画；使用公共固定时长，退出控件立即不可交互。

## 发布配置与格式

发布者在构建前配置 `resources/update-channel.json`。配置编入主进程，界面不允许改写地址，也不能通过网络响应扩大允许下载的域名。当前正式配置为空，准确显示“更新服务尚未开放”；不虚构上线地址。

```json
{
  "feedUrl": "https://updates.example.com/stable.json",
  "downloadOrigins": ["https://downloads.example.com"]
}
```

以上仅为脱敏格式示例，不能当作正式服务。更新源返回：

```json
{
  "schemaVersion": 1,
  "channel": "stable",
  "releases": [
    {
      "version": "1.2.0",
      "platform": "darwin",
      "arch": "arm64",
      "publishedAt": "2026-10-05T00:00:00Z",
      "notes": ["修复已知问题", "改善撰写体验"],
      "classificationVersion": "2026.01",
      "systemRequirement": "macOS 14 及以上",
      "downloadUrl": "https://downloads.example.com/mac-arm64"
    }
  ]
}
```

- `platform` 为 `win32`、`darwin`、`openharmony`；`arch` 为 `x64`、`arm64`。客户端将 `ohos` 归一为 `openharmony`。平台分别发布，不能拿另一端的版本判断当前端已是最新。下载页应对应该端发行渠道；鸿蒙商店管理的安装使用其正式商店入口。
- `version` 必须是严格稳定 [SemVer 2.0.0](https://semver.org/spec/v2.0.0.html)；比较按数字及预发布优先级，忽略构建元数据。`classificationVersion`、`systemRequirement` 可选，不从说明文字猜测。数据库随对应发行包更新，本功能不在线替换分类数据库。
- JSON 不超过 256 KiB，最多 200 个发行记录，字段与文本长度受校验限制。说明只按文本渲染，无 HTML、脚本或远程图片。
- 检测地址和下载地址只允许 HTTPS、无 URL 凭据或片段；检测请求拒绝重定向。下载必须匹配构建时配置的完整 origin。浏览器后续跳转仍由官方站点负责，发布者须维护可信下载页、有效 TLS、发行身份与签名；客户端不会执行下载文件。
- 正式源发布前须验收对应安装包，先上传已签名的发行包／可信下载页，再发布元数据；不能覆盖已公开的相同版本。此 JSON 用于第一阶段，不能作为后续 `electron-updater` 自动安装清单。

## 数据与安全

主进程发起无 Cookie、无认证凭据的静态 GET，不在路径、参数或请求体发送专利、客户、本地路径、安装 ID、版本统计或硬件标识。服务器仍会自然收到联网 IP 和基本 HTTP 信息；发布前在隐私说明列出服务主体、域名、日志用途和保留期限，不能把检测日志转为另一个未说明的统计功能。

检测偏好位于本机设置；成功检查时间、跳过版本、稍后时间以原子写保存到独立 `software-updates.json`。损坏的提醒历史可安全忽略；不会触碰文档资料。此历史不进入 PATDOC 或迁移包。便携设置迁移保持目标设备已有的联网检测开关，不迁移另一设备的选择。开发及测试资料与正式资料隔离。

检测、提醒 IPC 限制到应用窗口主 frame；渲染端只能提交操作与版本，不能提交任意下载 URL。状态在预加载桥接和界面两侧使用严格契约。并发检查复用一个请求；超时中止，关闭／退出取消，停用后拒绝迟到通知。提醒偏好与检查时间按字段串行合并并原子保存，避免关闭提醒后立即检查覆盖用户刚保存的选择。
