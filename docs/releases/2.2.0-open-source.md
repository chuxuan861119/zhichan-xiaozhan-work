# 知产小栈 Work 2.2.0 开源发行

知产小栈 Work 是面向中国专利撰写的专业编辑器。本次源码发行汇集了外观设计、修图、二维 CAD、文稿与平台适配的分批更新。可从本发行页下载源码，也可检出 `v2.2.0` 标签。

## 更新内容

- **外观设计专利工作台。** 新建外观设计案件后，可在同一工作区整理图片、编辑简要说明并导出材料。专利库支持按外观设计类型筛选。
- **小栈修图。** 支持图层、选区、蒙版、自由变换、裁切补边、撤销重做，以及兼容的栅格 PSD。可将分层工程随案件保存，继续编辑后再把结果应用到视图。
- **六视图与申报材料。** 支持视图分配、批量对齐像素尺寸并联动目标值、标记省略视图和预览代表图。简要说明增加产品变体及静态或动态图形用户界面场景。支持导出白底 JPG 视图、DOCX 或 PDF 简要说明，也可生成 ZIP。
- **二维 CAD 与附图标记。** 改进局部放大图插入尺寸、嵌套标记与填充显示，修复缩放后的旧预览及阵列完成后的选择状态。
- **文稿与工作区。** 聚集标尺保留完整段落编号。取消关闭案件可从原标签继续编辑。暂时切离流程图工作区时会保留编辑器尺寸。
- **平台与依赖。** 改进鸿蒙公共目录下的专利库迁移、备份、平板触控和工具栏布局。更新桌面依赖，并补齐构建时包含独立修图页面的配置。
