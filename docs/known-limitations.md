# 知产小栈Work 0.1.0 已知限制

- `v0.1.0-rc.1` 已因确认存在编辑后立即关闭应用时的数据丢失缺陷而作废；该候选版不得继续分发，现有标签仅作为不安全候选版的历史记录保留。
- DOCX 导入支持常见段落、文字格式、列表、表格、嵌入图片和常见公式，但不承诺还原 Word 的全部复杂对象或逐像素排版；SmartArt、图表、文本框、OLE/ActiveX、宏和加密文件受限或拒绝，导入前必须核对预览提示。
- 0.1.0 不生成 CNIPA XML，也不能直接提交专利申请。
- DOCX、PDF 和打印使用不同排版引擎，分页可能不同；Word 中的显示不承诺与 PDF 逐像素一致。
- 打印中心预览使用应用生成的分页 PDF；真实双面、颜色、纸张、每张页数等输出仍取决于 Windows 打印机驱动和具体设备能力。
- 复杂公式可能转换为图形。原始 LaTeX 会保留在导出信息中，导出报告会说明降级位置和原因。
- 安装包未进行代码签名，Windows 可能显示“未知发布者”或 SmartScreen 提示；本版本不声称具有发布者证书。
- 异常退出后会在下次启动显示恢复检查结果；恢复边界仍以内部文档库已经确认写入的修订为准，尚未进入主进程的输入法组合文本不在恢复范围内。
- WPS 可能与 Microsoft Word 存在轻微排版差异，正式交付前应在目标办公软件中检查。
- 手动覆盖已有 `.patdoc` 时，为避免并发覆盖造成数据丢失，旧版本仍会以同目录下点号开头、带随机标识的 `.recovery` 文件保留；当前版本不会自动清理既有隐藏 recovery 副本，这些副本可能累积占用磁盘空间，需要用户确认无用后手动清理。定时备份已改为独立版本文件并自动轮换，不再因覆盖同一文件持续产生 recovery 副本。
- 定时备份生成的便携 PATDOC 未加密。请只选择本人可访问的本地文件夹或受保护磁盘；需要跨设备迁移时，请使用密码保护的 `.zxwbackup` 完整数据包。
- 本版本不提供自动更新。升级需运行新的安装程序。
- 普通 SVG、PNG、JPEG 和 WebP 导入流程图编辑器后是一个完整图形对象，不能恢复为原文件中的独立节点和连线；只有 `.drawio`/XML 或含 draw.io 源数据的 SVG/PNG 能完整恢复编辑结构。
- 流程图源工程的修改不会自动更新已经导出的说明书附图，需要用户再次执行“导出至说明书附图”并确认替换。删除源工程会保留静态附图，但之后不能从该图重新打开已删除的工程。
- 首版流程图不支持 VSDX、Gliffy、Lucidchart、PlantUML、CSV、SQL、GIF、动画 SVG、HTML 和网络 URL 导入，也不提供云端图库、插件、发布或共享功能。
- “检查问题”由离线的专利一致性检查引擎提供，但“未发现问题”仅表示当前确定性规则未命中，不等于申请文件已经满足全部法律、形式或实质审查要求。
- 首期检查不判断新颖性、创造性、充分公开或权利要求保护范围，也不提供自动修复；这些事项仍需专利专业人员复核。
- 本地检查与可选的 AI 纠错、文字润色是不同功能。本地检查在本机执行，不会上传专利内容；用户主动使用 AI 功能时，任务文字、必要上下文及连续润色会话会发送至所配置的模型服务。模型验证会发送测试内容，读取模型列表会携带必要凭据。本地模型也受“允许连接 AI 服务”总开关控制；关闭连接不能撤回已发送的数据。具体范围见用户手册“AI 纠错和文字润色”及“设置 → AI 使用与隐私”。
