## 范围与口径

沿用受限 Nginx 日志，不增加浏览器脚本、访客标识、Cookie、指纹、来源追踪或第三方服务。后台不输出 IP、查询参数和原始访问时间明细。新增能力是页面口径、固定产品分组、自动化分类、小时趋势和同范围 CSV，不宣称 UV、会话、真人访问、停留时间或转化率。

- 页面：HTML GET 的 200 / 304，排除公开 404 页面；301、HEAD、静态资源不计为页面。纯本地缓存且不请求服务器的访问仍不可见。
- 路径：合并根目录/index.html、产品/index.html 和已知旧 HTML 地址；不把不同文档混为同一页。
- 分类：已识别自动化、未命中特征、旧日志无标记三类，逐日及各维度之和与页面请求一致。未命中特征不等于真人。
- 产品：品牌、Work/Search/AI/Manage 产品介绍、Work 文档、帮助/政策和其他页面独立；不把文档访问归为产品介绍访问。
- 小时：北京时间，选定日期范围内最近 72 小时截至最后一条页面记录；无记录小时不补零或连线。完整小时数据可导出。
- 导出：每日汇总、页面、产品、小时四类网站 CSV 共享日期范围与认证；软件 CSV 不受影响。旧报表 schema 未更新时显示等待新版，不伪造缺失指标为零。
