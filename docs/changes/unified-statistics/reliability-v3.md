3. 真实性边界：无用户账号、稳定设备标识或受信硬件证明，不能证明不同随机凭据来自不同真人/安装；不承诺精确 DAU。补充重复/冲突/拒绝/限流诊断，不能按正文去重，也不把嵌入安装包的公共密钥当成客户端身份认证。
4. 后台：区分配置开放、接收已验证/实际接收状态、固定日报状态；明确最新可发布日、预计发布时间和没有数据的具体原因。版本筛选包含已开放版本。默认按已结束窗口选择最近日报；网站筛选保持原语义。接入技术详情收起，日报和单一发行分组的固定逐日趋势优先展示，禁止用跨组总数反推小样本。
