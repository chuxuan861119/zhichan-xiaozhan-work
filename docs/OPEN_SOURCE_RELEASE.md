## 文件范围

保留 src、build、resources、scripts、tests、tools、platforms、services 及项目配置中与该基线有关的代码和材料。services 中的匿名统计实现属于同一基线，用于客户端集成测试和自有服务研究，不包含线上数据库或凭据。

排除官网页面和部署目录、代理记忆、内部计划、与应用构建无关的生产运营脚本。保留使用、平台构建和测试需要的文档。12 张 README 演示图也取自同一基线，不使用后续版本截图。

逐文件原始 Git blob 与 SHA-256 见 [基线清单](releases/1.1.8-source-manifest.json)。未列为开源适配的应用文件应保持与该清单一致。

## 必要的开源适配

这些是基于旧版制作公开源码发行的变更，不来自后续功能版本：

1. 新增已确认的图文 README、GPL-3.0 文本、NOTICE、构建及发布说明。
2. package.json 和锁文件增加 GPL-3.0-only 元数据及公开仓库地址，应用版本仍为 1.1.8，依赖版本不升级。
3. 将内置许可说明和对应文档调整为 GPL，取消对本开源版的企业另行授权限制；第三方许可继续保留。
4. 默认清空官方生产统计和官方二进制更新渠道，不修改其客户端实现；测试使用独立测试地址。
5. 更新对应许可和渠道测试，增加公开基线验证脚本，并忽略本地组件生成的上游源码及编译目录。基线提交已将“局部放大”工具移到“修改”组，其旧测试仍查询“绘图”组；本次仅同步该测试的查询，不修改 CAD 业务实现。来源清单列出所有适配文件。
6. 校正旧 PATDOC 导入失败测试和快照资源测试的资料：资源必须被正文引用才会进入基线既有的资源过滤与校验流程；测试补充引用以实际触发第二个资源导入失败、检测已引用资源损坏，不修改导入与快照实现。README 对照源码说明已移除的“其他文档”入口，避免沿用历史手册中过时的功能描述。
7. 同步旧 draw.io 阴影和快捷键测试到基线实际使用的 CSS 变量、分组数量；补齐恢复失败测试中的资源引用。只更新测试与手册的发行范围提示，不改变绘图、快捷键或恢复实现。
