## 1. 快速上手

知产小栈Work 面向中国发明专利和实用新型专利撰写。编辑、保存、本地检查、导出和打印主要在本机完成。AI 功能需要单独配置；不配置 AI 不影响常规写作。

### 第一次使用

1. 打开软件，进入专利库。
2. 若已有旧电脑导出的完整数据包，可从欢迎提示进入完整数据恢复；没有时直接开始使用。
3. 在“设置”中确认默认模板、页边距和快捷键。
4. 设置快照和独立目录中的定时备份。
5. 点击“新建专利”，选择发明或实用新型，填写专利名称。

建议先用一件测试专利熟悉编辑、备份和导出流程，再录入正式资料。

### 一件专利的推荐写作顺序

1. 建立专利，确认名称和类型。
2. 撰写权利要求书，按需登记附图标记。
3. 使用说明书转换工具生成段落草稿，粘贴后补充具体内容。
4. 导入说明书附图，整理图号和附图说明。
5. 补充摘要，选择摘要附图。
6. 运行本地检查，逐项核对结果。
7. 确认保存完成，导出并检查最终文件。

以上是建议流程，不限制先写说明书或先整理附图。

## 2. 认识工作界面

本软件采用为专利撰写设计的编辑界面，让注意力集中在技术内容和文档结构上。

**连续长页面：**编辑时，正文在一张连续延伸的长页面中展开，不被传统纸张页面之间的空白反复打断，便于连贯撰写、阅读和对照较长的专利内容。

**不显示段落标记：**不同于传统文字处理软件（如 Word 或 WPS）开启格式标记后的视图，本软件不在每段末尾显示段落标记，让页面更加整洁、干净。

段落结构仍然保留，按 Enter 可正常分段。连续长页面只是编辑视图，导出和打印仍按纸张及版式设置分页；交付前请检查预览。

### 平台与快捷键

本手册介绍 Windows、macOS 与鸿蒙桌面版本的共用功能。字体、托盘及开机启动能力可能因平台和安装环境不同，以当前软件的提示为准。

文中的 Ctrl 快捷键主要按 Windows／鸿蒙说明；macOS 查找为 ⌘F、替换为 ⌘⌥F，其余快捷键以菜单及快捷键设置中显示的组合为准。

| 编辑 | 撤销、重做、剪切、复制、粘贴、全选、查找和替换 |
| 插入 | 在当前文档中插入可用的权项、表格、图片、公式或图形 |
| 格式 | 文字、段落、页边距和清除多余格式 |

### 工具栏与功能栏

- 顶部工具栏放置常用操作；空间不足时，部分操作收进最右侧的更多工具菜单。
- 右侧功能栏提供当前书册相关工具，例如插入从权、说明书转换、增补编号、附图排序及智能辅助。
- 同一功能在不同入口出现时，作用范围仍以当前操作的文档为准。

### 悬浮功能介绍

将鼠标停在已配备详细介绍的按钮上，可阅读功能说明、示例、使用步骤和快捷键。

- “详细介绍”默认开启。
- 关闭任一面板上的开关，其他同类面板也切换为简洁模式。
- 简洁模式保留功能说明、快捷键和切换开关。
- 鼠标移到其他按钮时切换介绍；移出按钮与面板区域后收起。
- 介绍面板本身不会执行按钮对应的文档操作。

不是所有按钮都有图文介绍；其余按钮可能仅提供简短提示。

## 3. 启动、托盘与退出

### 关闭窗口不等于退出

启用“关闭窗口时最小化到系统托盘”时，点击主窗口关闭按钮会隐藏窗口，程序继续在后台运行。托盘入口及窗口关闭按钮的位置依操作系统而不同。

- 从托盘图标可恢复主窗口。
- 要彻底退出，请右键托盘图标选择退出软件，或使用软件“文件”菜单中的退出命令。
- 彻底退出时应等待保存和必要的数据处理完成，不要直接结束进程。

### 修改关闭方式

进入“设置 → 启动与关闭”，关闭“关闭窗口时最小化到系统托盘”，即可改变窗口关闭行为。

### 开机启动

在同一页面开启“开机启动”。在支持的平台和安装环境中，登录系统后软件在后台启动，不自动弹出主窗口。

开机启动选项仅在支持的安装环境中可用，临时测试实例不能设置。此项是当前电脑的设置，换电脑后应重新确认。

## 4. 管理专利库

### 新建与查找

点击“新建专利”，选择专利类型并填写名称。客户名称可以留空；专利名称和客户名称分别最多输入100个字符。

可按专利题目或客户搜索、按类型筛选，并在单栏、双栏和图文视图间切换。专利按创建月份分组，月份内按创建时间从新到旧排列。

图文视图可展示名称、类型、客户、摘要、附图及时间信息。悬停摘要或附图可查看预览；双击专利卡片或预览可打开专利。

### 搜索五书正文

1. 在专利库搜索框旁开启“搜索正文”。
2. 首次使用时，按提示选择“先建立索引”，或只搜索已有索引。
3. 输入关键词，查看匹配的专利、书册和文字片段；打开相应结果核对原文。
4. 若提示结果不完整或内容已更新，更新正文索引或刷新搜索结果。

正文索引仅在本机处理五书中的可检索文字，不识别图片中的文字，也不等于搜索其他文档。尚未索引或索引未更新的内容可能搜不到；搜索失败时仍可按题目和客户查找。

进入“设置 → 内容搜索”，可控制“后台建立内容索引”，或使用“立即索引”“停止”。关闭后台索引不会删除已有索引，已有结果可能逐渐过时。索引不随完整数据包迁移，新电脑需要重新建立。

### 专利设置

使用专利条目的三点菜单修改专利信息或进入其他操作。修改名称、类型或附图配置后，应核对正文中已有的文字，不要认为手工输入的所有称谓都会自动替换。

### 回收站

- 移入回收站不是立即永久删除。
- 回收站中的专利和文档保留1年（365天），可以恢复或手动永久删除。
- 永久删除前确认存在可靠备份；回收站不能撤销已经完成的永久删除。

## 5. 导入现有文档

### 导入 PATDOC

PATDOC 用于在专利库之间传递单件专利。

1. 在导入菜单选择 PATDOC。
2. 选择文件，按提示完成导入。
3. 打开导入的专利，核对五书、附图和相关工程。

软件会检查文件格式和完整性；未来版本、损坏或校验不通过的文件会被拒绝。导入不会覆盖来源文件。PATDOC 不等同于整个专利库的完整数据包。

### 导入 DOCX

1. 在导入菜单选择 DOCX，可一次选择一个或多个文件。
2. 查看导入预览，确认各文件对应的书册。
3. 处理重复分配和转换警告，再确认导入。
4. 导入后检查段落、公式、表格、图片顺序及文字内容。

五书合一文件会按可识别的独立标题拆分；单书文件只填入识别到的书册，其他书册保持空白，不加载默认模板。

无法可靠识别类型的内容默认进入“其他文档”。同一正式书册被重复分配时，需要在预览中调整，软件不会擅自合并。

摘要附图不能由 DOCX 直接填入正式摘要附图书册；相应内容会进入待选择的其他文档，之后仍需从说明书附图中选择正式摘要附图。

说明书附图按嵌入图片顺序导入，普通文字题注不会变成图片的一部分。

**注意：**

- 原 DOCX 不会作为源文件自动存入专利库，请自行保留。
- Word 的复杂对象和排版不保证完整转换；重点核对文本框、SmartArt、图表等内容。
- 宏、加密文件、危险对象和超过安全限制的文件可能被拒绝；外部链接不会自动加载。
- 需要保留整件专利的原生资料时，优先使用 PATDOC。

## 6. 五书、其他文档与同屏双显

### 五种正式书册

| 书册 | 内容 |
| --- | --- |
| 权利要求书 | 权项及其技术特征 |
| 说明书 | 技术领域、背景技术、发明内容、实施方式等 |
| 说明书附图 | 正式附图及排列顺序 |
| 说明书摘要 | 摘要正文 |
| 摘要附图 | 从说明书附图中选择的图片 |

此外，同一件专利可以包含多个“其他文档”，用于保存辅助材料。其他文档不会自动进入正式五书的合并导出、五书检查或附图标记同步。

发明专利可以按实际情况配置附图书；实用新型保留附图相关书册。关闭附图书时，已经手工写入文字文档的图号仍需自行核对。

### 文档标签与状态

点击上方书册标签切换。状态点用于提示基础结构或保存状态：

- 绿色：基础结构完整。
- 橙色：缺少必要内容。
- 蓝色：正在保存。
- 红色：保存失败。

悬停状态点查看具体说明。绿色不代表法律合规、没有技术问题或能够获得授权。

### 同屏双显

点击“同屏双显”，可同时查看两个文档，例如权利要求书与说明书、权利要求书与附图。

- 两侧分别切换、滚动和缩放，也可查看不同专利的文档。
- 操作前先点击需要编辑的一侧。
- 可在设置中配置自定义双显组合，左右两侧可选择文档、流程图或 CAD标号，并为组合设置快捷键。
- 窗口过窄时会退出双显；放大窗口后可重新开启。

## 7. 文字编辑与格式整理

### 基本编辑

**专为专利撰写设计：连续长页面，不显示段末标记。**正文连续展开，减少纸张分页空白和段落符号的视觉干扰，让长篇专利文档更便于连贯编辑，页面更加整洁。

不显示标记不等于取消段落：按 Enter 仍可分段，导出和打印仍会分页。

文字书册支持输入、粘贴、字体、字号、粗体、斜体、下划线、上下标、文字颜色、突出显示、段落对齐、行距、表格和分页等。

使用撤销、重做回退或恢复最近的文档操作。撤销不是备份，也不要用它恢复已经永久删除的专利或代替历史快照。

较长文档粘贴后，等待界面响应再继续批量操作；大量图片、表格和公式可能比相同字数的纯文字占用更多资源。

### 选区工具栏

选中文字后，附近出现工具栏，可直接修改常用文字格式。它持续显示时位置保持稳定，重新选择后才重新定位。

点击文字颜色或突出显示图标选择颜色，图标同时反映颜色。点击外部或按 Esc 收起。

右键菜单中的“显示选区工具栏”可控制是否自动显示，关闭后仍可使用正文右键菜单。

### 右键菜单

正文中右键或按 Shift+F10 打开菜单。

- 点在选区内：保留原选区。
- 点在选区外：以右键位置作为操作目标。
- 无选区时剪切、复制不可用。
- 鼠标移到带箭头的菜单项，展开侧面的子菜单。
- 表格、图片、公式等对象会出现对应操作。

### 查找与替换

在文字文档中使用“编辑 → 查找／替换”，或 Ctrl+F、Ctrl+H。核对当前文档和匹配范围后执行替换，尤其谨慎使用全部替换。

### 清除多余格式

用于整理**当前整份文档**，不是只清理选中的文字。

| 清除 | 保留 |
| --- | --- |
| 文字颜色、突出显示、斜体、下划线 | 粗体、字体、字号、上下标 |
| 空行、多余空格、连续下划线占位符 | 图片、表格、公式 |

有意保留的颜色和空白也可能被整理。操作后检查结果，不合适时及时撤销。

**表格内仅清除文字颜色与突出显示，其余样式、空白和表格排版保留。**

### 数字加括号与去括号

先选中文字，再点击工具栏中的“数字加括号”或“数字去括号”。工具栏放不下时，可在“更多工具”中找到。没有文字选区时，两个按钮均不可用。

| 功能 | 处理前 | 处理后 |
| --- | --- | --- |
| 数字加括号 | 关键词1、关键词201 | 关键词(1)、关键词(201) |
| 数字去括号 | 关键词(1)、关键词（201） | 关键词1、关键词201 |

加括号时，连续的阿拉伯数字作为整体处理，已有圆括号的数字不重复添加。去括号时，会移除选区内的中英文圆括号、方括号和花括号，保留其中的文字和数字。

两项操作只作用于选区，保留原有文字格式，支持撤销、重做。悬停按钮可查看示例，通过“详细介绍”开关切换详细或简洁面板。

### 结构标尺、字数与缩放

说明书结构标尺辅助定位章节和段落，不进入导出文件。界面缩放、菜单字号和工具栏显示大小不等同于正文的字体字号。

## 8. 权利要求与说明书辅助写作

### 权利要求编号

权利要求书不允许全文没有任何权项编号。权项应具有明确编号，如“1.”“2.”“3.”，从1开始连续排列，并统一分隔形式。

“其特征在于”前可包含主题名称和现有技术特征。不要把该短语前的所有文字都理解为专利名称。

### 插入从权

1. 将光标放入希望被引用的权利要求。
2. 点击“插入从权”。
3. 在新增段落末尾继续填写技术特征。
4. 核对调整后的编号和引用关系。

新从权插在光标所在权项之后，默认引用当前项；其他权项编号和相关引用做适应性调整。软件的自动调整不能代替对权项逻辑和保护范围的核对。

### 转为说明书内容

在权利要求书功能栏展开“说明书”，选择“发明内容”或“具体实施方式”。

1. 完善需要转换的权利要求。
2. 点击对应子按钮，先查看生成的预览。
3. 核对内容后点击“复制并跳转”，软件复制草稿并跳转到相应章节。
4. 在合适位置粘贴，再修改补充；取消预览不会修改正文。

**点击按钮并不等于已把转换内容写入说明书，仍需粘贴。**

转换内容是写作草稿。具体实施方式还应补充部件关系、实现过程和工作原理，不能只复制权利要求后就结束。

### 发明内容开头设置

“发明内容”旁的三点按钮可打开设置，选择常用的从权段落开头或自定义表述，例如“进一步地”。也可进入“设置 → 编辑辅助 → 发明内容设置”调整。

设置影响之后生成的内容，不会自动重写以前粘贴的段落。

## 9. 附图、附图说明与附图标记

### 添加附图

进入“说明书附图”，通过导入、粘贴或拖放添加图片。添加后核对清晰度、方向和排列顺序。

正式附图集中放在说明书附图书册。文字文档内插入的图片与正式附图不是同一个概念。

### 附图排序

1. 点击“附图排序”进入排序模式。
2. 鼠标拖动图片到目标位置。
3. 点击“完成排序”。
4. 核对新图号和附图说明。

系统按当前排列更新图号。正文中的手工图号和跨段表述仍应人工复核，不要假定所有手工文字都会自动调整。

### 删除与摘要附图

选中图片后可使用删除操作；附图页支持 Delete、Backspace，以及 Ctrl+A 后批量删除。批量删除前确认选中范围。

摘要附图从现有说明书附图中选择，不是单独再导入一张无关联的图片。附图排序后，显示图号按新顺序计算。

### 附图说明

右侧面板用于维护每张图的文字说明。新增附图会按辅助模板生成说明；面板中的编辑可同步到说明书“附图说明”章节。

说明书中以“图N”开头的独立说明段落用于匹配图片。一个图号对应多段说明、多个图号挤在同一段或无法唯一识别时，软件会暂停同步，要求先整理。

需要使用“填入说明书”时，点击后检查目标章节。自动生成或同步写入的说明文字使用红色，方便复核。

示例：

> 图1为本发明的整体结构示意图。
>
> 图2为本发明的局部结构示意图。
> 其中，1、底座，2、支撑杆。

### 登记附图标记

附图标记用于维护部件关键词与编号的对应关系。

1. 在权利要求书中选中关键词。
2. 使用“顺序编号”，或用“自定义编号”指定数字。
3. 在附图标记列表中核对名称和编号。
4. 按需使用“填入说明书”写入附图说明部分。

开启零部件定位后，单击列表关键词可定位、高亮正文；双击可编辑列表关键词。按界面提示确认修改，不要把列表修改理解为任意正文的全局替换。

“移出标记”用于移出登记，保留正文与编号。当前版本不提供可开启的跨文档同步修改开关。

### 增补编号

适用于说明书“具体实施方式”中**已经登记附图标记、但后补文字遗漏编号**的关键词。

1. 确认关键词已在附图标记列表登记。
2. 在说明书中点击“文档工具 → 增补编号”。
3. 查看结果并核对补入的位置。

增补的关键词与编号一起显示为紫色，原有已编号词组保持不变。成功时提示增补数量，并平滑定位到首处；没有遗漏时提示无需增补。

它不会替未登记的新部件自动决定编号，也不能代替对其他章节的核对。该功能可设置快捷键。

### CAD标号：导入与编辑

CAD标号是面向专利附图的二维绘图编辑工作区。可新建图纸、导入和编辑 DWG/DXF，添加引线、编号和局部放大图，生成专利附图，也可将当前 CAD 图纸导出为可继续编辑的 DWG/DXF。

1. 打开一件专利，从“插入 → CAD标号”或工作区中的 CAD标号入口进入。
2. 点击“新建图纸”开始绘制，或点击“导入图纸”选择 DWG、DXF、PDF 或图片；PDF 按提示选择页码。
3. 在功能栏的“CAD工具”中使用绘图和修改工具。可绘制直线、矩形、正多边形、圆、圆弧、椭圆、样条曲线、文字等，也可绘制齿轮、链条和弹簧示意图；选中对象后可移动、复制、旋转、缩放，并使用修剪、打断、偏移等工具修改。
4. 根据画布提示确定操作位置。选中的图形可直接拖动，控制点用于调整对应形状或参数；按住滚轮平移画布，滚动滚轮缩放，Esc 取消当前操作。绘图和修改支持撤销、重做。
5. 选择“标号”，点击引线起点，再点击放置编号；也可按住左键拖出引线，松开完成。调整编号与引线位置，核对编号与部件的对应关系。

剖面填充成功保存后，会记住图案、比例、角度、填充策略和缺口容差，下次使用沿用这些参数；预览、取消或失败不会覆盖上次成功的设置。双击已有填充时，优先显示该填充自身的参数。

缺口容差留空时自动处理局部微小缺口，输入 `0` 要求严格闭合，也可输入明确容差；容差仅参与填充计算，不会修改原线条。明显开口应先修补，不能仅依赖自动容差。修剪剖面填充时，点击切边划分出的待移除区域，保留另一侧填充及原图形；孔洞不是可修剪的填充区域，无法确定有效切边时不整块删除填充。

功能栏顶部可切换“CAD工具”和“附图标记”，会记住上次选择。使用尚未登记的数字标号后，可在浮窗中选填关键词，将该编号加入附图标记列表；也可通过列表旁的加号手动新增。误填的编号、关键词可在附图标记组件中编辑；没有可定位正文的位置时，不显示“定位问题”。登记不等于已经为正文编号，仍需按需使用“增补编号”。

DWG/DXF 导入后应核对图形及导入检查提示，特殊对象可能无法完整转换。新导入文件上限为 DWG 50 MiB、DXF 100 MiB；超限时可在源软件中拆分需要的附图。PDF 和图片作为底图使用，不能直接按 CAD 线条编辑，必要时可作为复杂原图的替代输入。

### CAD标号：取图与局部放大

- CAD 图纸直接使用选择／框选选中需要输出的线条、图形、标号和局部放大图，再进行预览或插入，无需单独框选取图范围。
- 在“CAD工具”中使用“局部放大”，按画布提示确定来源区域、引线和放大图位置。CAD 放大图包含来源区域的线条，不只是底图图片的放大。
- 选中局部放大图后，可调整位置、大小、字母及倍率；来源图形修改后，可使用“从来源更新”刷新放大内容。
- PDF 和图片保留相应的底图取图操作；界面缩放只改变观看比例，不等于输出图片尺寸。

### CAD标号：预览与插入

1. 完成绘图和标号后，选中所需成图内容，点击“预览成图”。
2. 检查范围、线条、编号及局部放大图；按需调整导出设置中的自动标号大小与比例。
3. 选择“导出 JPG”保存独立图片，或“插入附图”加入当前专利的说明书附图。
4. 需要替换已有附图时，使用“替换附图”选择目标并核对预览，确认后检查图号、附图说明和摘要附图。

自动调整标号大小可能提示重叠；应调整布局后重新成图，不会自动移动编号替您解决重叠。工作稿与正式附图是两个阶段：后续修改工作稿后，需重新预览并插入或替换，正式附图不会自动刷新。

需要继续在其他 CAD 软件中编辑时，在 CAD 功能栏使用“导出 DWG”或“导出 DXF”。这与导出 JPG 不同：DWG/DXF 导出当前工作稿的 CAD 图形、标号、引线和局部放大内容，不是仅导出当前选择的图片。请检查目标文件的内容和字体；转换不保证保留原文件中所有特殊对象的专有属性。PDF、图片底图不等同于可编辑的 CAD 图元。

## 10. 表格、公式与化学结构式

### 表格

从插入菜单或正文右键菜单插入表格。将光标放入表格后，功能栏只提供“结构”和“内容”两组：行列增删、合并拆分、左右及居中对齐、首行标题。行高随文字自动增长，无需设置行距、留白或精确尺寸。

仍可拖动表格边线调整行高、列宽；手动行高是最小高度，文字较多时会继续展开。右键菜单提供恢复自动行高、平均分布行高/列宽、自动分配列宽、清空内容和删除表格。清空内容不会删除表格结构；合并单元格的还原入口位于拆分设置内。

表格以文档正文宽度为限，不随窗口大小或界面缩放改变。插入列、粘贴及 Word 导入时，能容纳的表格自动调整宽度，不删文字、不缩小字号；列数过多而无法容纳时取消操作，请减少列数或拆成多张表后重试。历史超宽表格仍可打开、编辑和保存，但需适配宽度后再导出或打印。

合并单元格前先确认选中范围；删除行列前确认其中没有需要保留的内容。复杂表格导出后应检查宽度、跨页和内容完整性。

需要在表格下继续写正文时，在最后一个单元格的文字末尾按一次右方向键，或点击表格右侧空白处，光标会停在表格外右侧。直接输入、粘贴或按回车即可进入下方正文；仅移动光标不会新增空段落。在下方段落开头按退格会先去掉首行缩进，再按退格才回到表格外；空段落同时移除，已有正文保留。继续按退格或左方向键才返回末格，不会直接删除表格。

### 公式

可插入数学公式、物理公式和化学方程式。

1. 将光标放在目标位置，打开对应编辑面板。
2. 选择可用的行内／独立公式形式，输入内容或使用模板。
3. 检查预览，确认插入。
4. 需要修改时，双击已插入对象重新编辑。

在说明书附图中打开公式编辑器时，使用“插入附图”，生成新的附图，而不是写入文字书册。

若提示不支持的命令或环境，先关闭提示并修改公式，不要把未成功插入的内容当作已经保存。

### 化学结构式

打开化学结构式编辑面板绘制或编辑结构，确认后插入到允许的目标位置。含可编辑源数据的对象可重新打开编辑；普通图片不能自动还原为可编辑结构。

### 图片与对象的编辑边界

从流程图导出的关联图片可重新打开源工程；普通截图和导入图片通常作为整体对象处理。复制、导出后应检查公式和结构式是否清晰完整。

## 11. 流程图与电路图

### 流程图

通过“插入流程图”创建或打开当前专利的流程图工程，一件专利可有多个工程。

- 可导入 draw.io 工程、XML，以及带源数据的 SVG、PNG。
- 普通图片导入后是整体图形，不能拆回原节点。
- 外部导出用于生成独立文件，不直接修改正式附图。
- “导出至说明书附图”可新增或替换已有的关联附图。

替换关联附图时保留原图号、顺序、显示宽度、附图说明及摘要附图选择。**修改工程不会自动刷新已经导出的正式附图，需重新执行导出。**

### 电路图

通过“插入 → 插入电路图”进入绘图工作区，使用电路图模式下的元件图形与连接线绘制。工程管理和导出方式与流程图共用；需要成为正式附图时，执行“导出至说明书附图”。

这是图形绘制功能，不提供电路仿真、参数计算或设计正确性验证。

## 12. 本地检查

本地检查是本地规则检查，不需要配置 AI。

1. 点击工具栏、功能栏或工具菜单中的“本地检查”。
2. 在检查面板点击“全文检查”。
3. 按“需处理”“待核对”“写作建议”等优先级及分类查看结果。
4. 使用定位操作跳到原文，修改后重新检查。

检查涉及权利要求、说明书、摘要、附图和附图标记中的文字、编号、引用、章节、数值、公式、表格等规则。

- “定位文字”定位具体证据；无法精确到文字时，使用前往段落或文档。
- 专利名称相关问题会引导进入专利设置。
- 正文改动后旧报告会标为过期，不能继续把它当作当前完整结果。
- 重新检查时可查看旧结果，也可停止正在运行的检查。
- 达到报告数量或计算限制时，会明确提示未完成，处理后可再次运行。

编辑过程中的后台轻量检查不等于全文检查。本地检查只辅助发现问题，不阻止继续编辑、保存或导出，也不能代替技术、法律和授权前景判断。

## 13. AI纠错与小栈AI助手

### 使用前配置

**实验功能：AI纠错与小栈AI助手目前处于实验阶段，效果与稳定性仍在完善。** 使用时，任务所需的正文、选中文字、输入要求及相关对话上下文会发送至用户自行配置的 DeepSeek 官方接口。请谨慎提交未公开专利及敏感信息，核对服务商的隐私政策和费用，并人工核实输出结果；已发送的数据无法撤回。

1. 进入“设置 → AI 设置”，添加 DeepSeek 模型配置并填写自己的 API Key。
2. 开启 AI 连接，阅读协议至底部、勾选同意后点击“同意并开启”；取消不会开启。
3. 返回文档，按任务使用 AI纠错或小栈AI助手。

**暂时仅支持 DeepSeek 官方 API，不支持 Ollama 或任意自定义接口。** 密钥保存在当前电脑，不随完整数据包迁移。

AI 连接默认关闭。旧设置若没有当前协议的同意记录，会保持关闭，已有模型、密钥与历史记录仍保留。完整说明可从“帮助 → 隐私政策／软件使用协议”和“设置 → AI 设置”查看。

关闭连接开关会阻止后续请求，并中止当前连接；已发送的数据无法撤回。开发／运营方服务器不解密、不中转、不留存用户 Key 与交互内容，本机仍保存加密 Key 和对话历史。

### AI纠错

**实验功能。** 可点击功能标题旁的提示符号查看数据传输与使用风险说明。

用于综合检查文字、标点、术语和内容一致性等问题。

1. 打开 AI纠错。
2. 选择“当前文档”，或先选中文字再选择选区范围。
3. 开始检查，等待建议。
4. 对照原文逐项核对，再接受、忽略或接受所选。

只有接受建议后才写入正文。检查期间继续修改过原文时，定位和接受会重新核对原文；不能直接套用不再对应当前文本的建议。

AI 结果可能错误或不完整。涉及部件含义、技术方案和保护范围时，尤其需要人工判断。

### 小栈AI助手：开始对话

**实验功能。** 可点击功能标题旁的提示符号查看数据传输与使用风险说明。

| 方式 | 操作 | 适合用途 |
| --- | --- | --- |
| 选中文字 | 选中正文 → 打开助手 → 输入要求并发送 | 润色、解释或讨论所选内容 |
| 不选中文字 | 打开助手 → 输入需求并发送 | 起草、讨论思路、补充表达 |

可提出具体要求，例如“保持技术含义不变，缩短这段有益效果”。

### 连续对话

在同一对话中继续追问、补充限制条件或要求修改，助手会结合上文继续回答。

> 你：限位块能防止滑块脱出，帮我写成有益效果。
>
> 助手：通过设置限位块，限制滑块的移动范围，从而防止滑块脱出。
>
> 你：再简洁一点，不要改变原意。
> 助手：通过限位块限制滑块行程，防止滑块脱出。

核对结果后再采用或复制到文档。不要把聊天中的建议当作已经验证的技术事实，也不要认为生成结果一定已写入正文。

## 14. Agent CLI

Agent CLI 是**实验功能**：让具有本机命令执行能力的外部 Agent，通过软件提供的命令入口读取、编辑和管理已授权资料。它与软件内的小栈AI助手不同，也不会因为开启而自动选择或安装一个 Agent。

### 准备与开启

1. 准备一个可在当前电脑执行命令的 Agent，并先确认其数据处理方式。
2. 从“工具 → Agent CLI”或“设置 → Agent CLI”进入。
3. 开启“启用 Agent CLI”，阅读使用与隐私说明至底部，按提示同意。
4. 保持软件运行，点击“复制 Agent 接入指令”。

入口默认关闭。首次开启不等于已经授予某件专利的读写权限；连接后还需要您在软件中确认授权。

### 把接入指令与任务一起交给 Agent

将复制出的完整接入指令和具体任务一次发给 Agent，例如：“连接当前软件，仅阅读我授权的测试专利，整理权项引用问题，不修改正文。”

接入指令包含当前实例的命令路径、连接位置及读取配套 CLI 手册的要求。使用当前软件生成的指令，不要猜测路径、套用其他实例的命令或公开转发接入信息。技术操作人员可通过指令中的 `manual --json` 读取完整命令参考。

Agent 发起配对后，软件显示授权请求。先核对请求来源、任务目的和范围，拒绝不认识的请求。取消或拒绝不会取得授权。

### 选择授权范围

| 范围 | 可执行的操作 |
| --- | --- |
| 无权限 | 无法通过 CLI 查看或操作对应专利 |
| 只读参考 | 查看和检查已授权专利，不能修改或导出其内容 |
| 完整权限 | 在授权范围内连续修改、删除或导出，无需逐步批准 |
| 全局权限 | 分别控制设置、模板、AI配置、专利库、其他文档及数据迁移等操作 |

仅授权任务确实需要的专利与全局能力。未授权专利对 CLI 不可见。使用完整权限时，不能把“有预览或暂存步骤”理解为每次写入仍需您再次确认；请先用测试专利验证任务。

若启用新建／导入权限，每轮授权合计最多新建或导入五件专利，包括 DOCX、PATDOC 导入；删除已经创建的专利不会返还额度。需要继续时，由您在软件中重新授权。

### 导入、导出与文件位置

软件可为任务分配工作目录；使用其他输入或输出文件夹时，由您在授权界面选择允许的目录。Agent 写出一个路径提示不等于软件已经授予该目录权限。

CLI 的文件权限只约束经软件接口执行的操作，不限制 Agent 通过操作系统自行读取文件、运行命令或联网。它不是外部 Agent 的系统沙箱。

### 调整、撤销与结束

- 在 Agent CLI 页面查看已授权连接，使用“调整授权”缩小或改变范围，保存后生效。
- 点击“撤销授权”可终止对应授权；关闭入口、退出软件或切换专利库也会使授权失效。
- 撤销不会恢复已经修改或删除的内容，也不会删除已导出的文件、日志或第三方已收到的数据。
- 查看实际文稿和保存状态，必要时利用快照或外部备份恢复；不要把 Agent 的完成回复当作已经核对过的交付结果。

### 外部 Agent 与软件 AI 的区别

软件内 AI 功能暂时仅支持 DeepSeek 官方 API，且受软件 AI 连接许可控制。外部 Agent 使用什么模型、是否上传资料，由该 Agent 的配置和行为决定，软件的 AI 开关不能阻止它自行联网。

未公开专利、技术秘密、客户资料及密钥不宜在不清楚数据边界的情况下交给外部 Agent。详细授权与隐私说明可在 Agent CLI 页面再次查看。

## 15. 默认模板

### 共用与分别设置

进入“设置 → 默认模板”。

- 默认关闭“发明与实用新型分别设置”，两种专利共用模板，利用动态类型文字区分。
- 若两种专利需要不同结构和正文，开启该开关后分别选择和编辑。
- 已有用户的保存设置可能不同，先查看当前开关状态。

### 模板来源

- 空白模板：新建三书时不预填正文。
- 系统默认模板：只读，由软件维护。
- 自定义模板：点击加号新建，最多五个。

使用系统默认模板新建专利时，填写的专利名称会以红色文字自动带入第1、2项权利要求的名称位置、说明书首行标题和摘要中的名称位置；未填写名称时，这些位置保留下划线空白供后续编辑。

新建的自定义模板是空白内容，可直接填写，不要求先打开一件专利。因此从专利库进入设置，也能创建模板。

### 编辑与管理

1. 选择或新建自定义模板。
2. 分别编辑权利要求书、说明书和说明书摘要。
3. 需要复用现有专利时，点击“填入当前文档内容”。
4. 使用“设为当前模板”选择新建来源。
5. 点击“保存设置”。

填入当前文档前，软件先保存当前专利。普通图片不进入模板，检测到时会提示数量；来源专利不会因此改变。

卡片三点菜单提供重命名和删除等操作。重命名可以确认或取消；删除需要确认，保存设置后生效，不删除已经创建的专利。删除当前使用的模板后使用系统默认模板。

### 动态文字与结构式

“专利题目”和“发明／实用新型”是随新建专利信息变化的动态内容，不是普通文字格式按钮，也不是化学结构式。

- “本”为普通文字；动态部分是“发明／实用新型”。
- 正文可组成“本发明”或“本实用新型”。
- 小标题可组成“发明内容”或“实用新型内容”，标题粗体可保留。
- 从当前文档提取动态题目有结构识别条件，不满足时保留原文。填写模板后应检查动态内容是否正确。

模板可保留支持的公式及含可编辑源数据的化学结构式。说明书附图和摘要附图不属于模板三书；附图说明和标号说明使用独立辅助模板。

模板只影响以后新建的专利，不会批量重写既有文档。离开未保存的模板页面时，按提示选择继续编辑或放弃。

## 17. 保存、快照与定时备份

### 自动保存

编辑内容持续写入本机专利库，不需要为每件专利单独选择文件位置。点击“保存”可等待当前保存完成并创建手动快照。

红色状态点表示保存失败，应查看原因并处理。关闭专利或彻底退出时，等待必要保存完成；不要用强制结束进程绕过提示。

### 三种保护方式

| 方式 | 用途 | 注意 |
| --- | --- | --- |
| 快照 | 恢复误编辑前的历史内容 | 与本机库一起存储，不能代替外部备份 |
| PATDOC定时备份 | 独立恢复单件专利 | 未加密，应保护备份目录 |
| 完整数据包 | 换电脑、重装或恢复整个专利库 | 需要密码，只能迁入空库 |

### 快照

在“设置 → 存储与备份 → 快照版本”查看历史版本、预览差异或立即创建快照；也可从“文件 → 快照版本”进入。自动快照策略在同一设置页的“快照设置”中调整。

恢复快照会创建一件新的恢复专利，不直接覆盖当前专利。确认恢复内容后再决定如何整理。

### 定时备份

在“设置 → 存储与备份 → 定时备份”启用并指定独立本地文件夹。备份保存的是已保存修订，不等于每一次键盘输入都立刻生成一个文件。

闲置一段时间、关闭专利和正常退出时，会按保护策略补齐未备份修订。

在“设置 → 存储与备份 → 备份文件”查看和恢复，也可从“文件 → 备份文件与恢复”进入。外部备份失败时，分清“内部专利库保存失败”与“专利库已保存但外部备份失败”，按提示重试。

尽量不要只在系统盘保留一份资料，并定期验证备份确实可读取。

## 18. 完整数据迁移

### 导出完整数据包

1. 进入“设置 → 数据迁移”。
2. 选择导出完整数据包。
3. 指定保存位置和新文件名。
4. 设置迁移密码并再次确认。
5. 等待导出和校验完成，妥善保存生成的 .zxwbackup 文件。

数据包包含专利库、资源、快照、流程图工程、默认模板及可移植设置。模板名称、三书内容、选择和相关辅助资源一并迁移。

AI密钥、外部备份目录、打印机等与当前电脑有关的设置不迁移。

### 在新电脑恢复

1. 安装并打开软件，确认目标专利库为空。
2. 从欢迎提示或“设置 → 数据迁移”选择恢复。
3. 选择数据包，输入密码。
4. 核对预览摘要，开始导入并等待完成。
5. 重新配置 AI密钥、备份目录、打印机等本机选项。
6. 打开恢复的专利，核对文档、附图及模板。

完整导入不能覆盖或合并已有专利库。密码不保存在软件中，忘记后无法找回；请将密码与数据包分开保管。

## 19. 导出与打印

### 选择正确格式

- PATDOC：整件专利的原生便携文件。
- DOCX：与 Word 等文字处理软件交换可编辑文档。
- PDF：固定版式预览、交付和打印。
- .zxwbackup：整个专利库及设置的迁移文件，不是单件专利提交文件。

可单书导出或五书合并导出。当前其他文档可单独导出为 DOCX、PDF，不自动加入正式五书合并。

### 五书合并顺序

说明书摘要 → 摘要附图 → 权利要求书 → 说明书 → 说明书附图。

每书从新页开始，页眉随书册变化，合并文件页码连续。导出会先等待保存，并读取确切保存版本。

### 导出后必查

检查标题、权项编号及引用、段落、表格跨页、公式、附图顺序、图号和清晰度。成功生成文件不代表专利内容已通过审查。

### 打印

打印中心提供预览，以及打印机、纸张、方向、边距、单双面、份数、页码范围、每张纸页数和缩放等可用选项。实际能力取决于打印机和驱动。

可直接打印，也可将当前打印预览另存为 PDF。

## 21. 常见问题与安全建议

### 点击关闭后软件仍在运行

通常是启用了关闭到托盘。右键托盘图标选择退出软件；或在启动与关闭设置中改变偏好。

### 为什么某个按钮不可用

先确认当前书册、选区、选中对象及是否正在处理任务。附图页、文字页和其他文档支持的操作范围不同；AI功能还需要有效配置和连接许可。

### 点了说明书转换，但正文没有变化

该操作先复制转换内容并定位章节，需要在目标位置粘贴，不是直接替换正文。

### 增补编号提示无需增补

核对目标是不是具体实施方式章节、关键词是否已经登记，以及该词组是否已有编号。未登记的新部件需要先确定和登记编号。

### 保存失败或编辑界面报错

1. 停止继续大量输入，记录错误信息和构建标识。
2. 检查磁盘空间及专利库位置是否可写。
3. 按界面提示重试；不要直接删除库文件或强制结束进程。
4. 若必须重新加载，恢复后检查最近的修改是否完整。
5. 问题持续时保留日志、专利库及最近备份，联系支持人员。

### 专利库无法打开

不要删除、移动、改名专利库目录。先按提示重试；若进入只读保护或人工恢复状态，不要自行拼接数据库与资源文件。

### 完整数据包无法导入

检查目标是否为空库、密码是否正确、文件是否完整。不要为了绕过限制直接清空仍有正式资料的专利库。

### AI连接失败

在“AI 设置”中检查连接许可、DeepSeek 模型配置、密钥和网络。不要把密钥贴进问题截图或公开日志。

### 本地资料与升级

在“设置 → 存储与备份 → 存储位置”查看实际专利库和备份位置。Windows 默认库位于 `%LOCALAPPDATA%\ZhichanXiaozhanWork\Library`；其他平台及临时实例使用不同目录，以软件显示为准。

本地数据库和资源文件不是应用层正文加密存储。请使用操作系统账户权限和磁盘保护；PATDOC、DOCX、PDF及普通外部备份也应妥善保管。

卸载软件默认保留专利库，重新安装后会继续读取原专利库。正常安装升级不应删除用户专利库，但升级、重装、换电脑或维修前仍应导出完整数据包并保留外部备份。

发现新旧数据目录冲突或旧库不兼容提示时，保留现场，按提示处理，不要自行删除旧目录来强行启动。

### 反馈问题时提供什么

软件版本及构建标识、所在页面、操作步骤、报错文字和脱敏截图。涉及文档复现时，优先提供去除技术秘密、客户信息和密钥的测试副本。

### AI Key 的系统保护与授权

打开 AI 设置只读取密钥保存状态，不访问系统加密服务。首次实际使用时按需解密，成功后仅在本次主进程内复用；退出、密钥删除或文件变更后不复用旧缓存。Key 始终以系统加密方式保存，不回显给设置页面。

Mac 使用钥匙串，授权由系统决定，不能承诺永不出现；稳定的应用签名可减少升级导致的重复授权。Windows 使用当前登录账户的 DPAPI 加密，通常不另行索取电脑密码。鸿蒙使用其 Electron 运行库提供的加密接口，实际提供方及授权行为需在真机确认。安全加密不可用或接口报告不安全的 `basic_text` 后端时拒绝保存，不回退明文或弱加密。

旧版密钥未解锁时显示“旧版加密密钥，使用时验证”；不为确认这个状态要求密码。首次成功使用后补齐非敏感的配置标识索引，不改变 Key 的加密内容。

### 软件更新

在“设置 → 软件更新”中查看当前版本、手动检查和控制自动检测。自动检测默认开启，发现新版后以轻量提醒通知；您可关闭提醒、稍后处理或跳过当前版本。帮助和关于窗口也提供“检查更新”。

建议保持开启。软件更新可修复已知问题、改善使用体验，并提供分类号数据库更新。关闭自动检测后仍可手动检查，日常编辑和保存不受影响。

“前往官方下载”会打开对应平台的官方下载地址，安装由您决定；安装前请保存文档并退出软件。更新说明中的分类号数据库版本表示该发行包随附的数据，检测本身不会修改数据库或专利。Windows 1.1.6 预览版已接入官网预览更新通道。1.1.2 及更早版本未配置更新地址，显示“更新服务尚未开放”时，请先从官网手动下载安装一次新版；此提示不表示当前已是最新版本。
