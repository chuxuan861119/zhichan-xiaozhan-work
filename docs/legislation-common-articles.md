# 常用法条选编

核对日期：2026-09-07。面向中国发明、实用新型的审查及撰写场景，不是基于审查意见样本统计的引用频率排名，也不是自动判断案件法律结论的工具。

## 来源与边界

- [专利法（2020年修正）](https://www.cnipa.gov.cn/art/2020/11/23/art_97_155167.html)
- [专利法实施细则（2023年修订）](https://www.cnipa.gov.cn/art/2023/12/21/art_98_189197.html)
- 选编以实施细则第五十条的初步审查范围、第五十九条的实质审查驳回事由以及相关撰写、修改条款为依据。没有官方频次统计，因此不标注“最高频”、频次或排名。
- 21组条款按授权条件、保护客体、撰写规范、修改与答复分类；条款原文直接从已内置的官方文本中提取完整一条，保留各款、各项及例外，不人工重写。
- 条号采用现行版本，旧审查意见引用的实施细则条号可能不同。实际适用应结合申请时间、过渡规定、通知书和案件事实。
- 本次不调整审查指南，也不将其内容作为独立法条重写。

## 交互

“常用法条”独立页面支持问题分类、条款简记标签和原文定位。卡片默认展开完整条文，允许手动收起；采用最多三列的错位排版，窄窗口自动减少列数。专利法与实施细则的 Ctrl+F 在包括标题按钮的整个法规弹窗范围内聚焦并选中查找词；保留搜索框、高亮、搜索框旁的结果计数、Enter/Shift+Enter、上一处/下一处。
