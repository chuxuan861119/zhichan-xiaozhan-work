# 完整数据迁移使用说明

完整数据迁移用于更换电脑、重装系统或把整个专利工作环境搬到新的 Windows
账户。软件会把完整专利库和可移植设置写入一个使用迁移密码加密的
`.zxwbackup` 数据包，再由新电脑的空专利库导入。

在新电脑完成导入、重启和内容核对之前，请保留旧电脑上的原专利库，不要把迁移
数据包当作唯一副本。

## 快照、实时备份和完整迁移有什么区别

| 功能 | 主要用途 | 保存范围 | 适合的场景 |
| --- | --- | --- | --- |
| 快照 | 在同一专利库中回到较早版本 | 单件专利的恢复点及其关联资源 | 误改内容后恢复、查看历史版本 |
| 实时备份 | 在指定目录持续生成便携 PATDOC | 按专利生成的 PATDOC，不包含整个专利库和全部设置 | 日常增加一份独立文件副本 |
| 完整迁移 | 把整个工作环境搬到空的新环境 | 专利库、回收站、快照、附件、默认模板目录、受支持的编辑器工程、历史草稿和可移植设置 | 更换电脑、重装系统、迁移 Windows 账户 |

实时备份生成的 PATDOC 当前不加密，应保存在仅自己可访问的本地目录或受保护磁盘。
完整迁移包则必须设置独立的迁移密码，但它不能代替日常快照和实时备份。

## 开始前必须知道

- 迁移密码必须为 **12～128 个字符**。软件不保存密码，也没有找回、重置或绕过
  密码的后门；**密码丢失后，数据包即无法恢复**。
- 不要复用 Windows 登录密码、邮箱密码或其他账户密码。密码提示不加密，不要在提示
  中填写密码本身、客户名称或可直接推断密码的信息。
- 将 `.zxwbackup` 数据包和密码分开保存，例如分别放在不同的受控介质或密码管理
  工具中。不要把密码写在数据包文件名或与数据包同目录的明文文件里。
- 导出和导入期间保持电脑供电，避免拔出移动设备或断开映射盘。开始前为源盘、目标盘
  和新电脑的数据盘预留足够空间。
- 完整迁移不会修改源数据包。迁移成功或失败后，都应先保留源数据包和旧电脑数据，
  直到新电脑上的内容已经核对且能够继续编辑、保存和再次导出。

## 哪些设置不会迁移

下列项目属于当前电脑或 Windows 账户，导入后必须重新设置：

- AI 密钥；
- 实时备份路径，且实时备份会保持关闭，直到重新选择目录并启用；
- 打印机设备；
- 窗口位置、大小等窗口状态。

发明和实用新型的默认模板目录会整体恢复，包括三个自定义槽位的名称和三书正文、
当前选择、附图辅助文字，以及化学结构式所需的预览资源。默认模板不包含说明书附图和
摘要附图；这两书属于各件专利自身的数据。页边距、快捷键、自定义双显组合、快照设置
和不绑定具体打印机的可移植打印偏好也会随包恢复。导入完成页会提示仍需在新电脑配置
的项目。

## 第一步：在旧电脑导出

1. 打开旧电脑上的专利工作台，确认需要迁移的专利都能正常打开。
2. 进入“工具 → 数据安全设置 → 数据迁移”，选择“导出完整数据包”。
3. 查看待迁移摘要。软件会先等待编辑、附件和草稿写入完成；如果保存失败，导出会停止，
   应先按提示解决保存问题。
4. 选择空间充足且连接稳定的保存位置。完成前只会写入临时文件；全量回读验证通过后，
   才会出现正式的 `.zxwbackup` 文件。
5. 输入两次相同的 12～128 字符迁移密码，并确认已经单独记录和妥善保管该密码。
6. 等待收集、压缩、加密和验证全部完成。进行正式发布时不要关闭软件、拔出设备或
   断开映射盘。
7. 记录导出完成页显示的数据量和数量摘要，把数据包与密码分开保存。
8. 在新电脑导入和核对完成前，不要卸载旧电脑软件、清空旧专利库或删除旧电脑数据。

如果需要把数据包复制到移动设备或映射盘，复制完成后应正常弹出设备，并在新电脑上
重新选择复制后的完整文件。不要使用仍在复制中的文件。

## 第二步：在新电脑的空库导入

1. 在新电脑安装能够读取该数据包版本的专利工作台。
2. 首次启动后，不要新建专利、导入 PATDOC、保存草稿或执行其他会写入专利库的操作。
3. 从首次欢迎页的“已有完整数据包？从旧电脑恢复”，或“工具 → 数据安全设置 →
   数据迁移”中的“导入完整数据包”进入导入流程。
4. 等待软件确认当前库为空，然后选择旧电脑导出的 `.zxwbackup` 文件。
5. 输入导出时设置的迁移密码。密码验证、文件认证、版本检查和暂存验证完成前，正式
   专利库不会被替换。
6. 核对预览中的正常专利、回收站、快照、附件、历史草稿、编辑器工程和数据量摘要。
7. 确认当前电脑无需保留其他专利数据，并确认导入后软件将自动重启。
8. 开始正式切换后，不要强制退出。该阶段不能取消；如果意外断电，软件会在下次启动时
   根据持久化记录安全继续或回滚。
9. 软件自动重启并完成二次验证后，检查完成页，然后抽查正常专利、回收站、快照、附件
   和编辑器工程。
10. 继续编辑一份脱敏测试内容，完成保存、关闭重开和再次导出，确认新环境可正常工作。
11. 重新配置 AI 密钥、实时备份目录和打印机，并按需要调整窗口状态。

## 为什么非空库会拒绝导入

完整迁移是“空库整体恢复”，不是合并、覆盖或自动清空工具。两个专利库可能包含相同
标识的专利、附件、快照、编辑日志或工程；直接合并会造成引用冲突，覆盖则可能永久
丢失新电脑上的数据。因此，只要主进程发现任何专利、回收站内容、历史草稿、快照、
编辑日志、附件、工程、待处理操作、未知文件或不可读取状态，就会在读取迁移包前拒绝
导入。

界面看起来没有专利，并不一定代表底层库严格为空。遇到“当前专利库不是空库”时：

1. 不要手动删除应用数据目录、数据库文件或恢复候选目录；
2. 先保护当前电脑已有数据，需要时为当前库单独导出或备份；
3. 改用尚未写入任何业务数据的全新环境，或联系技术支持确认安全处理方式；
4. 注意：在同一 Windows 账户卸载后重装通常仍会保留内部专利库，不能据此认定库已清空。

## 常见错误与处理

| 提示或现象 | 应该怎么做 |
| --- | --- |
| 密码不正确或数据包无效 | 检查是否选择了正确数据包、输入了导出时的完整密码。为避免泄露校验细节，错误密码和部分包头损坏可能显示相同提示。不要反复猜测；确认记录后重试。 |
| 数据包损坏、被篡改、截断或版本不兼容 | 停止导入，不要修改当前空库。重新从受信任的旧电脑复制或重新导出；如果提示包版本过高，安装不低于提示版本的软件。 |
| 磁盘空间不足 | 按提示确认不足的是导出源盘、导出目标盘还是新电脑数据盘。释放足够空间或改用空间充足的稳定位置后，从头重试。不要把未完成的临时文件改名为 `.zxwbackup`。 |
| 保存位置不可用、移动设备被拔出或映射盘断开 | 恢复设备、网络盘和权限，或改用稳定的本地位置，然后重新开始。确认旧专利库和正式迁移包仍保留。 |
| 导入已回滚 | 软件已经恢复原来的空库，源迁移包保持不变。先处理提示中的原因，再重新导入。 |
| 显示“需要人工恢复”或 `manual-safe-recovery` | 立即停止编辑，不要删除、重命名或移动任何迁移候选目录，也不要自行重装或清空应用数据。保留迁移包和旧电脑数据，记录界面上的任务编号与发生阶段，联系技术支持。软件会保持只读，以避免猜测状态后误删或混合数据。 |

处理任何错误时，都不要把旧电脑数据或源迁移包作为“清理空间”的首选删除对象。只有在
新电脑完成重启后二次验证、人工抽查、继续编辑与再次导出后，才能根据自己的保留策略
处理旧设备。
